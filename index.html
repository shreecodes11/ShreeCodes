Projects

Leukemia Cell Classification using ResNet50 + Grad-CAM

Developed a deep learning model for classifying leukemia cells using ResNet50 transfer learning. Grad-CAM was applied to visualize important regions influencing predictions, improving model interpretability in biomedical image analysis.

Kaggle Chest X-ray EDA

Exploratory Data Analysis on a chest X-ray dataset focusing on class imbalance detection, image dimension variability, dataset quality inspection, and visualization.

Notebook Summary: Converted image folders into structured dataframe, analyzed class imbalance, studied image size distribution, visualized samples, checked corruption, and concluded preprocessing needs.

link

OTSeg-inspired Multi-Prompt CLIP Prototype

A CLIP-based prototype inspired by OTSeg for zero-shot semantic segmentation. It evaluates multiple text prompts against an image and ranks them using similarity scores.

Built as an initial step to understand multimodal attention and prompt-based vision-language alignment.
